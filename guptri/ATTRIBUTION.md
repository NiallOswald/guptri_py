# Attribution for Bundled GUPTRI Code

This package bundles portions of the **GUPTRI** Fortran software. ^1^   
GUPTRI is a Fortran library for computing generalized upper triangular forms and for analyzing regular and singular matrix pencils. ^1^ 

## Original authors

The original GUPTRI software is attributed to:

- **James Demmel** ^1^ 
- **Bo Kågström** ^1^ 

A software archive hosted by UC Davis identifies **GUPTRI** as a Fortran 77 package by James Demmel and Bo Kågström, with a listed date of **1999**. ^1^   
Additional archival material also associates GUPTRI with the work of **J. Demmel and B. Kågström** on singular matrix pencils and Kronecker structure computations. ^2^ 

## Historical references

Relevant published references associated with GUPTRI include:

- J. Demmel and B. Kågström, *The generalized Schur decomposition of an arbitrary pencil* $$A - \lambda B$$, 1993. ^4^ 
- J. Demmel and B. Kågström, *Stably Computing the Kronecker Structure and Reducing Subspaces of Singular Pencils* $$A - zB$$ *for Uncertain Data*, in *Large Scale Eigenvalue Problems*, 1986. ^2^ 

## Modifications in this package

The bundled Fortran sources in this package are based on the original GUPTRI code by **James Demmel** and **Bo Kågström**. ^1^   
They have been **modified for packaging, integration, compatibility, and maintenance purposes** by the maintainers of this Python package.  
Unless otherwise noted, those modifications do **not** imply authorship of the original GUPTRI algorithms or software design.
